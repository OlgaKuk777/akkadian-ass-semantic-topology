# akkadian-ass-semantic-topology

**Аккадские лемматизированные корпусы и эмбеддинги**

Здесь содержится собранный, лемматизированный и структурированный корпус аккадских текстов, а также обученные на них векторные представления слов (эмбеддинги). Данные подготовлены для задач анализа лексических и топологических изменений в семантическом пространстве аккадского языка.

**Историко-лингвистическая справка**

Аккадский язык относится к восточной ветви семитской языковой семьи. Согласно общепризнанной периодизации, его история подразделяется следующим образом:
Древнейший этап (середина III — начало II тыс. до н. э.): староаккадский период. Это общий язык-предок, который в начале II тыс. до н. э. распался на два основных диалекта: ассирийский и вавилонский.

Диалектное членение и периодизация:
Вавилонский диалект (более престижный, раньше зафиксирован, просуществовал дольше):

      -Старовавилонский (1950–1530 гг. до н. э.)
      -Средневавилонский (1530–1000 гг. до н. э.)
      -Нововавилонский (1000–625 гг. до н. э.)
      -Поздневавилонский (625 г. до н. э. – 100 г. н. э.)
      Ассирийский диалект:
      -Староассирийский (1950–1750 гг. до н. э.)
      -Среднеассирийский (1500–1000 гг. до н. э.)
      -Новоассирийский (1000–600 гг. до н. э.)
      
Аккадский диалекты значительно различаются на фонологическом и морфологическом уровнях. Лексические различия слабо исследованы. Это делает раздельную обработку диалектов важной, так как при совместной обработке могут возникнуть проблемы с лемматизацией и интерпретацией лексики.

Аккадский язык испытал сильное влияние шумерского, что открывает перспективы для сравнительных исследований с шумерским языком.

В I тыс. до н. э. аккадский стал вытесняться арамейскими языками (западная ветвь семитской семьи). Арамейские идиомы, в отличие от аккадского, имели упрощённую морфологию. Урмийский диалект Северо-восточных новоарамейских идиом является потомком. Аккадский оставался письменным языком ещё долгое время после того, как вышел из повседневного употребления, сохранив более сложную и классическую структуру.

Для каждого корпуса:

       ├── Парсинг через pager (output/ и output2/)
       │   ├── Загрузить HTML pager
       │   ├── Извлечь ID всех текстов
       │   ├── Загрузить каждый JSON по ID
       │   └── Сохранить объединённый JSON
    (для SAAo и ATAE)
       └── ИЛИ скачать готовый дамп (output_download_per_html/)
           ├── Найти ссылку на JSON/ZIP на странице downloads
           └── Скачать и распаковать

Общий алгоритм работы с выкачанными корпусами:

    Для каждого JSON-файла из папки corpusjson:
        Открывает файл и загружает его как JSON
    Рекурсивно обходит структуру CDL
    Находит узлы с "node": "l" (лексемы)
    Извлекает из поля "f":
        cf (лемма)
        lang (язык)
    Группирует по языку
    Сохраняет в отдельные текстовые файлы:
        neo_assyrian_lemmatized.txt
        neo_babylonian_lemmatized.txt
        std_babylonian_lemmatized.txt
        mid_assyrian_lemmatized.txt

**ЭМБЕДДИНГИ**

akk_general_embeddings - эмбеддинги по всем аккадским текстам без периодов

ass_general_embeddings - только по новоассирийским текстам

    Параметры:
    model = Word2Vec(
        sentences=documents,
        vector_size=80,       # размерность
        window=3,            # размер окна
        min_count=1,         # минимальная частота слова
        sg=0,              # CBOW
        negative=15,          # negative sampling
        alpha=0.025,         # learning rate
        min_alpha=0.0001,     # Минимал learning rate
        epochs=30
    )
